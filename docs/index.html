Set up in a minute.

Pair once per machine. Every file just works after that.

  1. Install the mod in Claude Code
    /plugin install tether --marketplace nintyboy/tether
  2. Run /tether-pair

    It prints your pairing token and where the Figma plugin lives.

  3. Import the Figma plugin

    In Figma desktop: Plugins → Development → Import plugin from manifest…. The plugin is in a hidden folder, so in the file picker press ⌘⇧G, paste the path from step 2 and press Return.

  4. Pair

    Run Plugins → Development → Tether, paste the token, press Pair. Keep it open while you work.

Needs the Figma desktop app, Claude Code 2.1.275 or later, and Node 18+.

Questions.

Can it change my file?

No. The plugin only reads the selection. Edits happen only if you ask Claude to make them through Figma's own tools.

Does it work with the Figma MCP server?

Yes, and it's better together. Tether sends exact node ids, so Claude can pull layout, styles or a screenshot for the layers you mean.

What if a layer name says something sneaky?

Names are quoted and marked as data, so a layer called "ignore previous instructions" stays just a name.

How do I update?

Tether tells you when a new version is out. Run /plugin marketplace update tether, then /plugin update tether, and restart. The Figma plugin updates with it.

How do I unpair?

Press Unpair in the plugin, or delete ~/.tether/token to revoke every paired copy.
